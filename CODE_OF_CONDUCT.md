# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, welcome newcomers, and keep discussion about the work. Harassment, discrimination, personal attacks and publishing others' private information are not accepted, in issues, pull requests, discussions or anywhere the project is represented.

Report unacceptable behaviour privately to the maintainers through GitHub (a private vulnerability report on this repository reaches them, or contact a maintainer directly). Reports are handled confidentially. Maintainers may remove comments, commits or contributions that don't follow this code, and may ban contributors who repeatedly or seriously break it.
